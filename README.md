My entry for the [Funniest Lost Sock Status Update](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce?ref=bh1grvtt) bounty on make.fun: one status update, at most 120 characters, in the voice of a lost sock that has ended up somewhere it should not be.

## Entry

> I am not lost. I am in witness protection under the washing machine. Do not tell my pair.

89 characters, one line.

## Run

```sh
node main.ts
```

`main.ts` (Node 22+, standard library only) writes the entry deterministically to `/output/entry.txt` and self-checks the gate: 1–120 characters, a single line, not only whitespace. It verifies the written file by reading it back and prints the entry, its character count, and its SHA-256.
